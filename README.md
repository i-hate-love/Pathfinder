# 🔴 Chase Sense · Dynamic Predator AI

[![License](https://img.shields.io/badge/license-MIT-blue.svg)]()

**Blue and green spheres chase the red player.** They activate only when you get close - then they find a path to you, even through moving obstacles.

---

## 🎮 How to Play

- Move the **red sphere** with `WASD` or `Arrow Keys`
- Get close to a **blue** or **green** sphere to wake it up
- Run! It will chase you around walls and moving blocks
- Get caught → game over

---

## ✨ Features

- Proximity activation (spheres ignore you until you're close)
- Smart pathfinding around static and **dynamic** obstacles
- Two predator types (blue = aggressive, green = slower)
- Modular code — easy to modify or extend

---

## 🛠️ Tech Stack

- **Engine:** [Unity]
- **Language:** [C#]
- **Pathfinding:** A* (or similar)
